# MeStory - Memorial Books Platform
## תוכנית הסבה לפלטפורמת ספרי הנצחה

**תאריך:** 2026-04-13
**גרסה:** 1.0

---

## 1. חזון המוצר

### 1.1 מהות המוצר
פלטפורמה המאפשרת למשפחות להנציח את יקיריהם באמצעות כתיבת ספר חיים - סיפור אישי המשלב זיכרונות, תמונות, מכתבים ועדויות מחברים ובני משפחה.

### 1.2 קהל יעד ראשי
- משפחות שכולות (חיילים שנפלו)
- משפחות שאיבדו יקירים
- עמותות תמיכה (גולני, צנחנים, יד לבנים וכו')

### 1.3 ערך ייחודי
- כתיבה מודרכת עם AI שמבין את הרגישות
- ספר שיתופי - מספר כותבים לספר אחד
- עיצוב מכובד ומותאם להנצחה
- ייצוא להדפסה מקצועית

### 2.1 ערוצי הכנסה

```
┌─────────────────────────────────────────────────────────────────┐
│                      מודל הכנסות                                │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  1. משפחות פרטיות (B2C)                                         │
│     └── תשלום ישיר עבור מנוי/ספר                                │
│                                                                 │
│  2. עמותות (B2B)                                                │
│     ├── מנוי שנתי לעמותה                                        │
│     ├── קופונים למשפחות תחת העמותה                              │
│     └── White-label אפשרי                                       │
│                                                                 │
│  3. מרקטפלייס                                                   │
│     └── עמלה ממכירת ספרים שמפורסמים                             │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 2.2 אפקט מתגלגל (Viral Loop)

```
עמותה → משפחות תחת העמותה → כותבים ספר → משתפים עם קרובים
                                              ↓
                               קרובים רואים ורוצים גם → לקוחות חדשים
```

### 2.3 ניהול Admin

| פיצ'ר | תיאור |
|-------|--------|
| ניהול עמותות | יצירת עמותה, הקצאת קופונים, מעקב שימוש |
| קופונים | יצירת קודי הנחה/גישה, תוקף, מגבלת שימושים |
| מעקב מקורות | מאיפה הגיעו משתמשים (עמותה/קופון/אורגני) |
| דוחות | שימוש לפי עמותה, המרות, הכנסות |

## 4. פיצ'ר חדש: ספר שיתופי

### 4.1 קונספט

```
┌─────────────────────────────────────────────────────────────────┐
│                    ספר שיתופי - Collaborative Book              │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  יוצר הספר (Owner)                                              │
│     │                                                           │
│     ├── מזמין תורמים (Contributors)                             │
│     │      ├── בן משפחה                                         │
│     │      ├── חבר/ה                                             │
│     │      ├── מפקד/ת                                            │
│     │      └── ...                                              │
│     │                                                           │
│     ├── כל תורם כותב את הפרק שלו                                │
│     │                                                           │
│     ├── היוצר מאשר/עורך                                         │
│     │                                                           │
│     └── ספר אחד מאוחד                                           │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 4.2 מודל נתונים חדש

```typescript
// Book model - הרחבה
interface Book {
  // ... existing fields

  // Collaborative fields
  isCollaborative: boolean;
  collaborators: Collaborator[];
  invitations: Invitation[];
}

interface Collaborator {
  id: string;
  name: string;
  email: string;
  role: 'owner' | 'editor' | 'contributor';
  relationship: string; // "אח", "חבר", "מפקד"
  assignedChapters: string[]; // chapter IDs
  joinedAt: Date;
  status: 'pending' | 'active' | 'completed';
}

interface Invitation {
  id: string;
  email: string;
  relationship: string;
  message: string; // הודעה אישית
  token: string;
  expiresAt: Date;
  status: 'pending' | 'accepted' | 'declined' | 'expired';
}
```

### 4.3 Flow

1. **יוצר הספר** יוצר ספר שיתופי
2. **שולח הזמנות** לתורמים (email + קישור)
3. **תורם מקבל** הזמנה ונרשם/מתחבר
4. **תורם כותב** את הפרק שלו (מנקודת המבט שלו)
5. **יוצר מאשר** ועורך את הפרקים
6. **פרסום** - ספר אחד מאוחד

## 6. AI מותאם להנצחה

### 6.1 Prompts מיוחדים

```typescript
const MEMORIAL_SYSTEM_PROMPT = `
אתה עוזר כתיבה רגיש ומכבד שמסייע במשימה החשובה של הנצחת יקירים.

הנחיות:
- השתמש בשפה מכבדת וחמה
- עזור להוציא זיכרונות יפים
- אל תהיה דרמטי מדי - תן למשפחה להוביל
- שאל שאלות פתוחות שמעודדות שיתוף
- הימנע מקלישאות על מוות ואובדן
- התמקד בחיים, לא במוות

סגנון:
- אישי ואינטימי
- מכבד את הכאב אך לא שוקע בו
- מעודד זיכרונות ספציפיים וחיים
`;
```

### 6.2 שאלות ראיון AI מותאמות

**פתיחה:**
- "ספר/י לי על [שם] - מה הדבר הראשון שעולה לך כשאת/ה חושב/ת עליו/ה?"
- "מה היה הדבר הכי מיוחד ב[שם]?"

**ילדות ונעורים:**
- "איך היה [שם] כילד/ה?"
- "יש סיפור מהילדות שתמיד מצחיק אותך?"

**אישיות:**
- "מה היה הדבר שאנשים אהבו הכי הרבה ב[שם]?"
- "מה הצחיק אותו/ה?"

**חברויות:**
- "מי היו החברים הקרובים?"
- "איך [שם] היה כחבר/ה?"

**חלומות:**
- "על מה [שם] חלם/ה?"
- "מה היו התוכניות לעתיד?"

**מסר:**
- "מה היית רוצה שאנשים ידעו על [שם]?"
- "מה המסר שהיית רוצה שיישאר מהספר הזה?"
