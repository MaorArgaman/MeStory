# MeStory — תוכנית סידור והעשרה

> **הבעיה המרכזית:** המערכת טכנולוגית ויפה, אבל **מסובכת מדי** לקהל היעד.
> סבתא בת 75 פותחת את האפליקציה, רואה 4 כפתורים, 8 ז'אנרים, 4 שלבים — ומוותרת.
>
> **הפתרון:** לא להוסיף עוד פיצ'רים. **לארגן מחדש** את מה שיש.

---

## בעיה 1: הדשבורד מציף

### מצב נוכחי
- 4 כרטיסי יצירה (מאפס, ראיון, קול, ייבוא) — המשתמש לא יודע מה לבחור
- 6 מודלים שונים שיכולים להיפתח
- ספרים קיימים עם 3 כפתורים לכל ספר

### מצב רצוי
```
┌─────────────────────────────────────────────────┐
│                                                 │
│  👋 שלום [שם], מה תרצה לעשות היום?             │
│                                                 │
│  ┌──────────────────────────────────────────┐   │
│  │  ✨ ספר לי את הסיפור שלך                 │   │
│  │  (ראיון קצר → ספר מוכן תוך דקות)        │   │
│  └──────────────────────────────────────────┘   │
│                                                 │
│  ── או ──                                       │
│                                                 │
│  📝 אני רוצה לכתוב בעצמי                       │
│  🎤 אני מעדיף לדבר                             │
│  📄 יש לי טקסט מוכן                            │
│                                                 │
│  ─── הספרים שלי ───                              │
│  [ספר 1]  [ספר 2]  [ספר 3]                      │
│                                                 │
└─────────────────────────────────────────────────┘
```

### שינויים ספציפיים
| מה | פעולה | למה |
|----|-------|-----|
| 4 כרטיסים שווים | כפתור ראשי אחד גדול + 3 אפשרויות משניות קטנות | המשתמש צריך לדעת מה **מומלץ** |
| 6 מודלים | לאחד ל-2: "ספר לי" (ראיון) + "כתוב בעצמך" (wizard) | 6 מודלים = בלבול |
| 13 ז'אנרים | מצמצם ל-5 ברורים | 13 ז'אנרים מבלבלים |
| כפתורי ספרים (Edit/Design/Publish) | כפתור אחד: "המשך" → לוקח לשלב הבא | 3 כפתורים = "מה ההבדל?" |

**קבצים:** `DashboardPage.tsx`
**מאמץ:** 4-5 שעות

## בעיה 2: Wizard יצירת ספר — 12 החלטות לפני שכתבת מילה

### מצב נוכחי
4 שלבים עם 12+ החלטות:
1. שם + ז'אנר (מתוך 8) + סוג (אישי/שיתופי) + 4 שדות memorial
2. AI brainstorm (מיותר)
3. מטרת כתיבה (קצר/בינוני/ארוך) + קהל יעד (4 אפשרויות)
4. בחירת template

### מצב רצוי — שלב אחד בלבד
```
┌─────────────────────────────────────────┐
│  📖 מה הסיפור שלך?                     │
│                                         │
│  שם הספר: [_________________________]  │
│                                         │
│  על מה הספר? (בחר אחד)                 │
│  ○ סיפור החיים שלי                     │
│  ○ זיכרון לאדם אהוב                    │
│  ○ סיפור משפחתי                         │
│  ○ עדות אישית                           │
│  ○ משהו אחר                             │
│                                         │
│  [    ✨ בוא נתחיל    ]                 │
└─────────────────────────────────────────┘
```

### מה מסירים
| מוסר | למה |
|------|-----|
| שלב AI Brainstorm | לא מוסיף ערך |
| "Writing Goal" (short/novella/novel) | המשתמש לא יודע מה זה novella |
| "Target Audience" | תמיד "family" לקהל שלנו |
| Template selection בשלב יצירה | ייבחר אוטומטית לפי סוג |
| 13 ז'אנרים | מצמצם ל-5 ברורים |
| שדות memorial בwizard | עוברים לתוך הראיון |

**קבצים:** `CreateBookWizard.tsx`
**מאמץ:** 3-4 שעות

## שלושת הכללים

> **כלל ה-3:**
> - **3 אפשרויות** מקסימום בכל מסך
> - **3 לחיצות** מקסימום עד "אני כותב"
> - **3 שניות** להבין מה כל כפתור עושה
>
> **כלל ברירת המחדל:**
> לכל החלטה צריכה להיות **ברירת מחדל ברורה**.
> אם 80% מהמשתמשים יבחרו אותו דבר — תבחר בשבילם.
>
> **כלל "אל תשאל":**
> אם אפשר לגלות את התשובה אוטומטית — **אל תשאל**.
> - שפה? זהה מהדפדפן.
> - ז'אנר? זהה מהתוכן.
> - קהל יעד? תמיד "משפחה" לקהל שלנו.
> - Template? בחר אוטומטית לפי סוג הסיפור.
