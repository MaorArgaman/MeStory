# MeStory - תוכנית פיתוח מדויקת

> **קהל יעד:** אנשים רגילים - לא סופרים, לא מעצבים.
> אנשים שיש להם סיפור ורוצים ספר. לא יודעים איך.
> **מבחן הצלחה:** סבתא בת 75 יכולה ליצור ספר לבד בלי עזרה.
> **רף איכות:** התוצאה צריכה להיראות כמו ספר שיצא בהוצאה לאור מקצועית — לא כמו פרויקט ביתי.

---

## סטנדרט איכות — "רמת הוצאה לאור"

כל ספר שיוצא מ-MeStory חייב לעמוד בסטנדרט הזה.
**זה לא פיצ'ר — זה תנאי סף.**

### עיצוב פנים הספר
| אלמנט | סטנדרט נדרש |
|--------|-------------|
| **טיפוגרפיה** | זוגות פונטים מקצועיים (כותרת + גוף). לעברית: David Libre + Rubik / Heebo + Frank Ruhl. לא Arial. לא Times. |
| **שוליים** | שוליים פנימיים רחבים יותר מחיצוניים (mirror margins) כדי שטקסט לא ייבלע בכריכה |
| **מספרי עמודים** | מיקום עקבי, פונט קטן ודיסקרטי, לא בעמוד כותרת / פרק חדש |
| **פתיחת פרק** | Drop cap או אות ראשונה מוגדלת, רווח עליון, קו מעוטר / אלמנט ויזואלי מפריד |
| **כותרות פרקים** | גודל ברור, פונט שונה מגוף הטקסט, מספר פרק + שם |
| **תוכן עניינים** | אוטומטי, עם מספרי עמודים מיושרים, קווים מנחים (dot leaders) |
| **ריווח** | line-height מינימום 1.5, paragraph spacing, רווח בין פרקים |
| **תמונות** | shadow / border עדין, כיתוב מתחת בפונט italic קטן, לא "מודבקות" על הדף |
| **עמוד שער** | כותרת גדולה, שם מחבר, שנה, עיצוב נקי — לא דף טקסט רגיל |
| **עמוד אחורי** | תקציר, תמונת מחבר (אופציונלי), ברקוד (לספר מודפס) |

### עיצוב כריכה
| אלמנט | סטנדרט נדרש |
|--------|-------------|
| **כריכה קדמית** | תמונה/איור מקצועי שתופס עין, לא רקע אחיד עם טקסט |
| **טיפוגרפיה** | כותרת בפונט display, שם מחבר בפונט קטן יותר, היררכיה ויזואלית ברורה |
| **כריכה אחורית** | תקציר, ציטוט מהספר, שם מחבר — הכל בפונט קריא על רקע נקי |
| **שדרה** | שם ספר + שם מחבר + לוגו MeStory — פונט אופקי, לא שוכב |
| **פלטת צבעים** | 2-3 צבעים מקסימום, הרמוניים, מותאמים לנושא |

### תמונות AI
| אלמנט | סטנדרט נדרש |
|--------|-------------|
| **סגנון** | עקבי לאורך כל הספר — לא פרק אחד watercolor ופרק אחד realistic |
| **רזולוציה** | מינימום 1024x1024 לכריכה, 512x512 לפנים |
| **רלוונטיות** | כל תמונה קשורה ישירות לתוכן הפרק — לא "תמונה יפה" סתם |
| **תיאום** | צבעי התמונות תואמים לפלטת הכריכה |

## שלב 1 — תיקוני UX קריטיים (2-3 ימי עבודה)

### 1.1 עורך פשוט כברירת מחדל
**בעיה:** toolbar עם 15 כפתורים מפחיד לא-סופרים.

**פתרון:**
- Toggle: "מצב פשוט / מצב מתקדם" ב-EditorToolbar.tsx
- **מצב פשוט (ברירת מחדל):** שדה טקסט נקי + מיקרופון + "✨ עזור לי" + Bold/Italic
- **מצב מתקדם:** ה-toolbar המלא כמו היום

**קבצים:** `EditorToolbar.tsx`, `BookWritingPage.tsx`
**מאמץ:** 3-4 שעות

### 1.2 Placeholder מנחה בפרקים ריקים
**בעיה:** פרק ריק = דף לבן = שיתוק.

**פתרון:** שאלות מנחות בעברית שנעלמות כשמתחילים להקליד:
- זיכרון: *"נסה להיזכר ברגע ספציפי. איפה הייתם? מה ראית? מה שמעת?"*
- סיפור חיים: *"התחל מהתחלה. איפה נולדת? מה אתה זוכר מהילדות?"*

**מאמץ:** 2 שעות

### 1.3 כפתור "✨ עזור לי" — תפריט AI בעברית
**בעיה:** "Generate continuations" לא אומר כלום לקהל היעד שלנו.

**פתרון — תפריט עם 5 אפשרויות ברורות:**
- "אני לא יודע איך להתחיל" → AI כותב פסקת פתיחה מותאמת לנושא הפרק
- "יש לי רעיון, תעזור לנסח" → AI שואל 3 שאלות קצרות → בונה פסקה
- "תשפר את מה שכתבתי" → AI משכתב ברמה ספרותית (לא רק grammar fix)
- "תמשיך את הסיפור" → continuation כמו היום
- "תוסיף עומק ופרטים" → AI מעשיר: ריחות, צלילים, רגשות, דיאלוגים

**איכות הפלט:** ה-AI לא סתם "ממשיך" — הוא כותב ברמה ספרותית:
- משפטים מגוונים (קצר, ארוך, שאלה, קריאה)
- דימויים ומטאפורות מותאמים לעברית
- סגנון אישי — שומר על הקול של המספר, לא סגנון רובוטי

**קבצים:** חדש `AIHelpMenu.tsx`, `BookWritingPage.tsx`, `geminiService.ts`
**מאמץ:** 6-8 שעות

## שלב 2 — תבניות סיפור ברמת הוצאה לאור (4-5 ימי עבודה)

### 2.1 מבנה תבנית — לא רק פרקים, גם עיצוב מלא

```typescript
interface StoryTemplate {
  id: string;
  name: string;               // "סיפור חיים"
  icon: string;
  description: string;
  chapters: {
    title: string;
    subtitle?: string;         // כותרת משנה לפרק
    guidingQuestions: string[];
    openingLine?: string;      // משפט פתיחה לדוגמה
    mood: string;              // "נוסטלגי", "חגיגי", "עצוב"
  }[];
  // עיצוב מקצועי מוכן לכל תבנית:
  design: {
    coverStyle: 'photo-overlay' | 'illustration' | 'minimalist' | 'textured';
    colorPalette: {
      primary: string;        // #2C3E50
      secondary: string;      // #E74C3C
      accent: string;         // #F39C12
      background: string;     // #FAFAFA
      text: string;           // #2D2D2D
    };
    fonts: {
      title: string;          // "Frank Ruhl Libre"
      chapter: string;        // "Heebo"
      body: string;           // "David Libre"
      caption: string;        // "Rubik"
    };
    layout: {
      margins: { top: number; bottom: number; inner: number; outer: number };
      fontSize: number;
      lineHeight: number;
      chapterStartStyle: 'new-page' | 'drop-cap' | 'ornament';
      ornamentStyle: 'line' | 'floral' | 'geometric' | 'dots' | 'star';
      pageNumberStyle: 'simple' | 'decorated' | 'none';
    };
    coverImage: {
      prompt: string;         // Prompt ליצירת כריכה ב-AI
      style: string;          // "watercolor portrait", "oil painting landscape"
      fallbackGradient: string[];  // צבעי gradient אם אין תמונה
    };
  };
}
```

## שלב 3 — "ספר לי" → ספר מוגמר ברמת הוצאה לאור (5-6 ימי עבודה)

### 3.1 זרימה: ראיון → ספר מקצועי אוטומטי

```
[1] משתמש בוחר תבנית (למשל "זיכרון לאדם אהוב")
         ↓
[2] AI מראיין: שאלה אחת בכל פעם (טקסט או קול)
    10-15 שאלות, ~20 דקות
    שאלות מותאמות לתבנית שנבחרה
    follow-up חכם: "תספר עוד על הרגע הזה" / "מה הרגשת?"
         ↓
[3] AI כותב ספר מלא (Gemini):
    - מחלק את התשובות לפרקים לפי מבנה התבנית
    - כותב פתיחות ספרותיות לכל פרק (לא "בפרק זה נספר על...")
    - מוסיף מעברים חלקים בין פסקאות
    - משלב דימויים ומטאפורות בשפת המספר
    - שומר על הקול האותנטי — לא "מנקה" את השפה
    - 4,000-8,000 מילים
         ↓
[4] AI מעצב ברמת הוצאה לאור:
    - מחיל את כל הגדרות העיצוב מהתבנית (פונטים, צבעים, שוליים)
    - מייצר כריכה קדמית עם AI (prompt מהתבנית)
    - מייצר כריכה אחורית עם תקציר
    - מוסיף drop caps, ornaments, page numbers
    - מייצר 2-3 תמונות פנימיות (רלוונטיות לתוכן, סגנון אחיד)
    - מוסיף תוכן עניינים אוטומטי
    - מוסיף עמוד הקדשה (אם רלוונטי)
         ↓
[5] המשתמש מקבל ספר מוגמר:
    - תצוגת ספר 3D מסתובב
    - "הספר שלך מוכן! רוצה לעבור עליו?"
    - כפתורים: "צפה בספר" / "ערוך" / "הזמן הדפסה" / "פרסם"
```

### 3.2 איכות הכתיבה — Prompt Engineering

ה-Prompt ל-Gemini חייב לייצר טקסט ברמה ספרותית:
```
אתה סופר ישראלי מנוסה שעוזר לאנשים להפוך את הזיכרונות שלהם לספר.
הכלל הכי חשוב: שמור על הקול של המספר. אל תנקה, אל תייפה יותר מדי.
אם המספר אמר "הוא היה גבר פשוט" — תשאיר את זה. אל תהפוך ל"היה גבר נעלה".

כללי כתיבה:
- פתיחת פרק: התחל בסצנה — לא בהסבר. "הדלת נפתחה" ולא "בפרק זה נספר על..."
- משפטים: מגוונים באורך. קצר. ואז ארוך יותר שמתפתח ומוסיף פרטים ומצייר תמונה.
- חושים: כל פסקה לפחות חוש אחד — ריח, צליל, מגע, טעם, מראה.
- רגשות: הראה, אל תספר. "הידיים שלו רעדו" ולא "הוא היה מרגש".
- סיום פרק: שורה אחרונה שנשארת — ציטוט, תמונה, או משפט קצר וחד.
```

### 3.3 איכות העיצוב — מה ה-AI מייצר אוטומטית

| אלמנט | מה קורה |
|--------|---------|
| **כריכה** | תמונת AI בסגנון התבנית (portrait שמן / watercolor / צילומי / מינימליסט) + כותרת + שם מחבר |
| **עמוד שער** | כותרת בפונט display גדול, שם מחבר, שנה, לוגו MeStory קטן |
| **הקדשה** | עמוד הקדשה מעוצב (אם המשתמש הזכיר למי מוקדש) |
| **תוכן עניינים** | אוטומטי, מעוצב, עם dot leaders ומספרי עמודים |
| **פתיחת פרק** | drop cap + ornament + כותרת פרק + כותרת משנה + רווח |
| **גוף טקסט** | פונט קריא, line-height 1.6, justify, paragraph indent |
| **תמונות** | 2-3 תמונות AI בסגנון אחיד, shadow עדין, caption בפונט italic |
| **מפרידי פרקים** | ornament / קו מעוטר / שלוש נקודות (***) — לפי סגנון התבנית |
| **עמוד אחרון** | ציטוט מהספר + "נכתב ב-MeStory" |
| **כריכה אחורית** | תקציר (500 תווים), שם מחבר |

**מאמץ:** 5-6 ימי עבודה

## שלב 4 — "סיים את הספר בשבילי" (2-3 ימי עבודה)

למשתמשים שכתבו תוכן אבל נתקעו.

### 4.1 כפתור חכם שמשלים מה שחסר
- כפתור בדשבורד: "✨ סיים את הספר"
- AI בודק checklist ומשלים:

| חסר | מה AI עושה | איכות |
|-----|-----------|-------|
| עיצוב | בוחר תבנית לפי ז'אנר + שפה | פלטת צבעים מקצועית, לא רנדומלי |
| כריכה | מייצר כריכה מותאמת לתוכן + ז'אנר | תמונת AI בסגנון מקצועי |
| Layout | מסדר margins, fonts, page numbers | mirror margins, drop caps, ornaments |
| תמונות | מייצר 2-3 תמונות לפרקים מרכזיים | סגנון אחיד, רלוונטיות גבוהה |
| תקציר | כותב סינופסיס 500 תווים | מעוצב לכריכה אחורית |
| TOC | מייצר תוכן עניינים | מספרי עמודים, dot leaders |
| הקדשה | מזהה ממי הספר ומוסיף הקדשה | עמוד נפרד, פונט italic |

**מאמץ:** 2-3 ימי עבודה

## שלב 5 — אלבום תמונות חכם (3 ימי עבודה)

### 5.1 העלאה מרובה + מיקום אוטומטי + עיצוב
- כפתור "העלה אלבום" — בחירת 5-20 תמונות בבת אחת
- AI (Gemini Vision) מנתח כל תמונה:
  - מזהה תוכן: "חתונה", "ילדים", "חייל", "נוף"
  - קורא תאריך EXIF → סידור כרונולוגי
  - מציע פרק רלוונטי
- **עיצוב תמונות אוטומטי:**
  - Shadow עדין (box-shadow, לא border שחור)
  - פינות מעוגלות קלות
  - כיתוב בפונט caption מתחת (italic, אפור כהה)
  - התאמת גודל לעמוד (לא חוצה שוליים)
  - אם תמונה ישנה/ירודה: שיפור אוטומטי (contrast, sharpness)

**מאמץ:** 3 ימי עבודה

## שלב 6 — תרומות משפחתיות (3-4 ימי עבודה)

### 6.1 תיבת תרומות — פשוט ומעוצב
```
בעל הספר שולח לינק/QR למשפחה
      ↓
בן משפחה פותח → דף מעוצב ופשוט (לא צריך הרשמה):
  ┌─────────────────────────────────────────┐
  │  📖 "סיפור חיים — אבא שלנו"            │
  │                                         │
  │  ✏️ שתפו זיכרון:                        │
  │  ┌───────────────────────────────────┐  │
  │  │ כאן כותבים...                     │  │
  │  └───────────────────────────────────┘  │
  │  🎤 או הקליטו (כפתור מיקרופון)         │
  │  📷 הוסיפו תמונה                       │
  │                                         │
  │  שם: [____________]                     │
  │  קרבה: [אח / אחות / ילד / נכד / חבר]  │
  │                                         │
  │  [    ✨ שלח זיכרון    ]                │
  └─────────────────────────────────────────┘
```

- **בעל הספר מקבל:** תיבת דואר נכנס עם כל התרומות
- **כל תרומה:** אפשר לאשר / לערוך / לדחות / לשייך לפרק
- **עמוד "תודות":** נוצר אוטומטית עם שמות כל התורמים
- **עיצוב תרומות:** ציטוט מעוצב (blockquote + שם + קרבה) — נראה מקצועי

**מאמץ:** 3-4 ימי עבודה

## שלב 7 — הדפסה פיזית (4-5 ימי עבודה)

### 7.1 Print-on-Demand
- **שילוב Peecho / Lulu API**
- כפתור "הזמן ספר מודפס" בעמוד Layout
- **אפשרויות הדפסה:**
  - כריכה רכה / קשה
  - נייר רגיל / כבד (120gsm / 170gsm)
  - גודל: A5 (סטנדרט) / A4 (מורחב)
  - כמות: 1-100 עותקים
- **תצוגה מקדימה:** 3D mockup של הספר הפיזי עם תמונת הכריכה
- **PDF מותאם הדפסה:** bleed marks, crop marks, CMYK conversion

### 7.2 אריזת מתנה דיגיטלית
- לינק מעוצב: "קיבלת ספר במתנה מ-[שם]"
- אנימציה של פתיחת מתנה → הספר נחשף
- כרטיס הקדשה אישי

**מאמץ:** 4-5 ימי עבודה

## שלושת הכללים

> **1. פחות בחירות = יותר ספרים.**
> כל החלטה שאפשר לקחת מהמשתמש — ה-AI יקח.
>
> **2. דיבור > כתיבה.**
> קהל היעד מספר סיפורים ליד שולחן שבת. תן להם לדבר.
>
> **3. ספר יפה > ספר מושלם.**
> ספר מוגמר בעיצוב מקצועי שווה יותר מטיוטה מושלמת שנשארת בדיסק.
> **הספר שיוצא חייב להיראות כמו הוצאה לאור — אחרת לא שילמנו.**
